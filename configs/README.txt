# ═══════════════════════════════════════════════════════════
# Config Analyzer — примеры конфигурационных файлов
# ═══════════════════════════════════════════════════════════
#
# Файлы для ручного тестирования и демонстрации:
#
# ┌─────────────────────────────────────────────────────────┐
# │ Формат JSON                                             │
# ├─────────────────────────────────────────────────────────┤
# │ bad_config.json      — все проблемы                     │
# │ good_config.json     — без проблем                      │
# │ partial_config.json  — только часть полей               │
# │ empty.json           — пустой объект {}                 │
# ├─────────────────────────────────────────────────────────┤
# │ Формат YAML                                             │
# ├─────────────────────────────────────────────────────────┤
# │ bad_config.yaml      — все проблемы                     │
# │ good_config.yaml     — без проблем                      │
# │ partial_config.yaml  — только часть полей               │
# │ empty.yaml           — пустой документ                  │
# ├─────────────────────────────────────────────────────────┤
# │ Формат YML                                              │
# ├─────────────────────────────────────────────────────────┤
# │ good_config.yml      — без проблем                      │
# └─────────────────────────────────────────────────────────┘
#
# ┌─────────────────────────────────────────────────────────┐
# │ REST/gRPC запросы                                       │
# ├─────────────────────────────────────────────────────────┤
# │ rest_reqs.txt        — curl-команды                     │
# │ grpc_reqs.txt        — grpcurl-команды                  │
# └─────────────────────────────────────────────────────────┘
#
# Быстрый старт:
#   ./bin/config-analyzer analyze configs/bad_config.json
#   ./bin/config-analyzer analyze configs/
